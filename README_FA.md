# راهنمای فارسی پروژه کنترل پیش‌بین با پایتون

## موضوع پروژه چیست

یک سیستم ساده داریم که ورودی آن شتاب و خروجی آن موقعیت است. می‌توان آن را
حرکت یک جسم با جرم واحد و بدون اصطکاک تصور کرد. هدف این است که جسم از موقعیت
صفر به موقعیت ۱ برسد و آنجا بماند. محدودیت شتاب هم باید رعایت شود.

کنترل‌کننده MPC با مدل ریاضی سیستم، چند قدم آینده را پیش‌بینی می‌کند. سپس
ورودی‌هایی را انتخاب می‌کند که خطای رسیدن به هدف و تغییرات ناگهانی ورودی را
کاهش بدهند. فقط اولین ورودی اجرا می‌شود و در قدم بعدی دوباره بهینه‌سازی انجام
می‌شود. این روش به آموزش شبکه عصبی یا دیتاست نیاز ندارد.

## روش اجرا

Python نسخه ۳٫۱۰ یا جدیدتر لازم است. فایل ZIP را استخراج کن و پوشه پروژه را
در VS Code یا ترمینال باز کن. به ترتیب این دستورها را اجرا کن:

```bash
python -m pip install -r requirements.txt
python mpc_simulation.py
python verify_mpc.py
python make_report.py
```

در ویندوز اگر دستور `python` شناخته نشد، به‌جای آن `py` بنویس. نمودارها به صورت
فایل ذخیره می‌شوند و پنجره جداگانه باز نمی‌شود. خروجی‌ها از قبل هم در بسته
قرار دارند تا بتوانی آن‌ها را ببینی.

MPC خود روش کنترل است؛ SLSQP حل‌کننده عددی مسئله بهینه‌سازی داخل آن است.

## سه آزمایش

۱. حالت پایه: پیش‌بینی ۱۰ قدم آینده، برنامه‌ریزی ۳ ورودی و محدودیت ورودی ±۱.

۲. محدودیت ورودی بیشتر: فقط محدودیت را به ±۰٫۴ تغییر می‌دهیم.

۳. پیش‌بینی بلندتر: فقط افق پیش‌بینی را از ۱۰ به ۲۰ قدم افزایش می‌دهیم.

زمان هر قدم ۰٫۱ ثانیه است؛ پس افق‌های پیش‌بینی ۱۰ و ۲۰ قدم برابر ۱ و ۲ ثانیه‌اند.
در هر سه آزمایش، سیستم از حالت سکون شروع می‌کند و مدت شبیه‌سازی ۱۰ ثانیه است.

## نمودارها را چطور بخوانم

در `results/response_comparison.png` نمودار بالا موقعیت را نشان می‌دهد. خط‌چین
مقدار هدف ۱ است. هرچه خروجی زودتر نزدیک آن قرار بگیرد و همان‌جا بماند، دنبال‌کردن
هدف بهتر است. عبور خروجی از مقدار هدف، فراجهش یا Overshoot است.

نمودار پایین ورودی یا شتاب اعمال‌شده را نشان می‌دهد. ابتدا ورودی مثبت جسم را
به سمت هدف حرکت می‌دهد؛ ورودی منفی سرعت آن را کم می‌کند. نزدیک هدف، ورودی و
سرعت باید به صفر نزدیک شوند. فراجهش بیشتر در حالت محدودیت ±۰٫۴ فقط نتیجه همین
تنظیمات و مدل است و یک قانون عمومی درباره همه کنترل‌کننده‌ها نیست.

RMSE خطای میانگین مربعی با ریشه است و کوچک‌تر بودن آن بهتر است. زمان نشست
۲ درصد، زمانی است که خروجی وارد بازه ۰٫۹۸ تا ۱٫۰۲ می‌شود و تا پایان شبیه‌سازی
از آن خارج نمی‌شود. اعداد دقیق در `results/metrics.csv` هستند.

## برای توضیح در کلاس

می‌توانی به انگلیسی بگویی:

> I implemented model predictive control for a double integrator in Python.
> The controller predicts future outputs and optimizes a sequence of control
> inputs while respecting input limits. I compared the baseline controller
> with a tighter input limit and a longer prediction horizon. The results
> show how these settings change settling time and overshoot.
